# Contributing

Suggestions are welcome, this list only stays useful if the community feeds it.

## Adding an entry

Open a pull request with one entry per PR. Format:

```markdown
- [Name](https://example.com) - One neutral sentence describing what it is and who it serves.
```

Rules:
- The link must be alive and point to the resource itself, not a marketing redirect.
- The project must be active within the last 18 months, or be an established reference.
- Descriptions are neutral: no superlatives, no "best", no marketing copy.
- Place the entry alphabetically within the right section.
- If you are affiliated with the resource, say so in the PR description. Affiliated entries are fine with disclosure; undisclosed self-promotion is removed.

## Removing an entry

Dead links, abandoned projects and resources that turned into pure ad pages are removed. Open an issue or PR with a short justification.

## Conduct

Be respectful. Disagreements about methodology or fiqh positions belong in the linked resources, not in this list.
